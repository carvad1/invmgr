# Invest Manager

Локальное Windows-приложение для учёта и анализа личных инвестиций в Беларуси. Светлый русский интерфейс, SQLite, бесплатные источники. Версия — 0.6.0.

![Обзор портфеля при первом запуске](docs/screenshots/overview.png)

## Быстрый старт

Если есть готовый установщик, запустите `release/Invest-Manager-0.6.0-Setup.exe`. Для запуска без установки распакованная сборка находится в `release/win-unpacked/Invest Manager.exe`; переносить нужно всю папку `win-unpacked`, а не один EXE.

### Навигация

- **Обзор:** стоимость, результат, ближайшие выплаты. История открывается кнопкой «Показать график».
- **Мои активы:** компактная таблица. Нажмите название для условий, причин покупок и операций.
- **Анализ → Облигации → Вставить из Aigenis:** вставьте результат Copy response и нажмите «Показать облигации». Загруженные выпуски доступны при переходах по разделам до закрытия приложения.
- **Анализ → По ссылке / каталог:** загрузка открытой карточки. Сохранённые сценарии находятся в «Мои расчёты».
- **Акции → Вставить из Aigenis:** постоянный список наблюдения и карточка компании. Отчётность, мультипликаторы, сигналы качества, DCF/DDM, обратный DCF, сценарии, история цены. [Методика и порядок работы](docs/STOCK_ANALYSIS.md).
- **Операции / Календарь выплат:** поиск, фильтры и страницы по 20 строк.
- **Настройки:** валюта, ориентир вклада, обновление источников, резервные копии и экспорт.

Для разработки нужен **Node.js 24 LTS x64**, npm и Windows 10/11:

```powershell
npm ci
npm run setup
npm run build
npm start
```

`setup` загружает официальный движок Electron. Для разработки с обновлением интерфейса: `npm run dev`.

```powershell
npm test                          # Финансовый учёт, SQLite, парсеры
npm run test:e2e                  # Проверка настоящего Electron через Playwright
npm run check:sources -- --live   # Проверка публичных источников (нужен интернет)
npm run pack                      # Приложение без установщика
npm run dist                      # Windows NSIS-установщик, без публикации
```

## Что работает

- **Быстрый просмотр облигаций:** на вкладке «Анализ» можно обновить открытый каталог, искать и сортировать выпуски, отдельно видеть купон, рейтинг и доступную доходность покупки. При вставке, если нет цены продажи, используется цена последней сделки и соответствующая доходность Aigenis с пометкой «По последней сделке · ориентир». Это сохранённый расчёт площадки на дату сделки, без пересчёта на сегодня. JSON карточек из вкладки Response веб-терминала Aigenis можно вставить вручную без HTTP-заголовков; это временный просмотр в окне приложения. Не вставляйте JWT, cookies и другие данные входа. Терминал требует авторизации (`401` без неё), поэтому его биржевые цены пока не обновляются автоматически.
- Для быстрого переноса карточки из вашей открытой вкладки Aigenis есть локальное [расширение Chrome/Edge](browser-extension/README.md) с кнопками «Скопировать облигацию» и «Скопировать акцию». Оно копирует только разрешённые поля ответа и не передаёт данные входа.

- **Быстрый анализ:** «Анализ» → «По ссылке / каталог» → ссылка Finstore на конкретный токен или `https://aigenis.by/bonds/` → выбор выпуска. Условия, опубликованный рейтинг, документы и проверка сохраняются в SQLite без создания покупки. Повторный выбор открывает сохранённую карточку; изменения в ней вносятся через «Условия».
- Ставка в процентах, процентный доход за горизонт в деньгах и процентах с целым количеством бумаг и комиссией. Индексируемые выпуски распознаются отдельно: простой прогноз отключён.
- Общая оценка по прозрачным правилам: «Недостаточно данных», «Есть факторы риска», «Высокий риск по данным», «Базовая проверка пройдена». Кредитный рейтинг отделён от рейтинга деловой репутации; отсутствие рейтинга не заменяется придуманной оценкой.

- Акции, облигации, долговые токены и депозиты, отдельно по площадке и валюте.
- Ручной ввод покупок, продаж, процентов, дивидендов, купонов, комиссий, пополнений и выводов. Редактирование и удаление с проверкой остатков.
- Причина **каждой покупки**, цель, горизонт, ожидания, риски и условия выхода.
- Денежные остатки, средняя стоимость, результат продаж, оценка открытых позиций, валютная переоценка, XIRR.
- Прогноз регулярных купонов, процентов и погашений. Полученный доход учитывается отдельно.
- Ежедневный автоматический расчёт начисленных процентов вкладов и XIRR с этой оценкой; actual/365–366, пополнения, снятия, капитализация и окончание срока. Поддерживается автообновляемая ставка НБРБ + надбавка с историей изменений.
- Анализ сценария покупки, сравнение с заданной ставкой депозита, YTM по регулярному графику, P/E, P/B, долг/капитал и маржа по введённой отчётности; SMA 20/50 и простой RSI 14 по сохранённым ценам.
- Публичные витрины [Finstore](https://finstore.by/kupit-tokeny/) и [Aigenis](https://aigenis.by/), [курсы НБРБ](https://api.nbrb.by/exrates/rates?periodicity=0). Источник и даты видны в интерфейсе.
- Резервное копирование и восстановление SQLite, экспорт операций и инвестиционных идей в CSV.

Первый запуск пустой: никаких выдуманных инвестиций. Нажмите «Добавить мой вклад», заполните условия и сохраните покупку. Для депозита **количество — сумма вклада, цена единицы — 1**. По умолчанию создаётся связанное внешнее пополнение на сумму покупки и комиссии. Если деньги уже внесены на счёт, снимите эту отметку.

По вкладам расчётные проценты автоматически включаются в результат и XIRR. Записанная фактическая выплата заменяет соответствующую расчётную сумму. При подтверждённой капитализации запишите выплату и покупку на эту сумму из остатка счёта. Автоматическая оценка не создаёт операций и не увеличивает доступные для расходов деньги. Авт расчёт можно отключить в карточке вклада.

## Данные и приватность

База установленной версии: `%APPDATA%/Invest Manager/data/invest.sqlite` (точный путь виден в настройках). Автокопии при запуске: соседняя папка `backups`, семь файлов по дням недели. Перед восстановлением создаётся дополнительная страховая копия рядом с базой. Восстановление заменяет текущие данные и запрашивает подтверждение.

**База и копии не зашифрованы; пароля и облачной синхронизации нет.** Защищайте их средствами учётной записи Windows. Ключи и пароли брокеров приложение не запрашивает. Каталоги площадок обновляются по команде. Для вкладов с привязкой к НБРБ публичная история ставок проверяется автоматически раз в день; персональные данные и параметры вклада в запрос не включаются.

SQLite, резервные копии, CSV, `.env`, локальные тестовые данные и установщики исключены из Git. Для переноса на другой компьютер используйте резервную копию, не GitHub.

## Границы первой версии

- Каталоги — открытые предложения с сайтов. Нет доступа к личным кабинетам, полному биржевому списку, стакану, автоматического импорта сделок или потоковых цен. Ручная котировка не заменяется ценой размещения из каталога.
- **Автосбор по акциям:** точное сопоставление по УНП на ЕПФР, финансовые документы, решения о дивидендах и корпоративные раскрытия. Выплаты Беларусбанка привязаны к конкретному классу акций. PDF, DOCX и XLSX читаются локально; русское/английское OCR сканов входит в установщик. Обновление раз в сутки при открытом приложении, ручное обновление одной/всех акций; настройка отключения в «Настройки». Результаты сохраняются без интернета. Рыночные цены Aigenis по-прежнему поступают через вставку Response.
- Автосбор не обеспечивает полное покрытие всех сайтов и документов. В одном проходе читается до шести новых документов; остальные доступны по кнопке. Неоднозначные и распознанные OCR финансовые числа не подставляются в мультипликаторы; проверенные финансовые показатели вводятся в карточке. Общерыночная лента новостей и автоматические исторические котировки не подключены.
- Токены Finstore рассматриваются как долговые инструменты. Анализ свободно торгуемых криптовалют, токеномики и ончейн-данных — отдельный будущий модуль.
- Нет автоматических торговых поручений, платного ИИ, MOEX, налогового расчёта и брокерских форматов импорта. MOEX и новые источники добавляются отдельными адаптерами.
- Налоговый модуль выключен по требованиям пользователя. Это не заключение о налогах в Беларуси.
- Сборка без платного сертификата подписи. Windows может показать предупреждение о неизвестном издателе.

npm ci
