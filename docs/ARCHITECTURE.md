# Архитектура

- Electron 44, React 19, TypeScript, Vite, Recharts, Lucide.
- SQLite из `node:sqlite` в главном процессе. Данные не хранятся в браузерном localStorage. WAL, foreign keys, synchronous FULL, транзакции для составных изменений, `user_version=1` для миграций.
- Таблицы instruments, operations, quotes, fx_rates, catalog, sync_runs, settings. Поля домена хранятся в JSON payload; идентификаторы и внешние ключи вынесены в отдельные SQL-колонки. Схемы домена проверяются Zod перед сохранением и при восстановлении.
- Движок расчётов `src/domain/finance.ts` чистый: используется интерфейсом и проверкой хронологии операций в главном процессе.
- Renderer: `nodeIntegration=false`, `contextIsolation=true`, `sandbox=true`, CSP, запрет навигации и новых окон. Preload предоставляет только именованные операции; главный процесс проверяет WebContents, главный фрейм и URL отправителя. Пароли/ключи не принимаются.
- Парсеры `electron/sources.ts` читают только разрешённые публичные HTTPS-адреса. Таймаут, ограничение размера ответа и запрет перенаправлений. Разметка сайтов не исполняется, в UI передаётся только текст. Ошибка не очищает старый каталог; источник и статус обновления сохраняются.
- Резервирование через SQLite backup API, а не копирование открытого WAL-файла. Восстановление проверяет целостность, версию, связи, схемы и денежные остатки; заменяет таблицы в одной транзакции после страховой копии.

Для новых площадок нужен адаптер со стабильным ID, раздельными номиналом/ценой/ставкой, временем загрузки и датой фактической котировки. Для брокерского импорта сначала нужны реальные обезличенные примеры отчётов; обязательны предпросмотр, проверка валют/комиссий и ключ дедупликации. Для MOEX понадобится отдельная политика пересчёта цены облигаций, НКД и корпоративных событий.

Тестовый запуск: `INVEST_TEST_MODE=1`, `INVEST_DATA_DIR` задаёт отдельную базу, окно скрыто. Оба параметра работают только в непакетной среде. Реальные личные данные для тестов не используются.

Источники реализации: [Electron security](https://www.electronjs.org/docs/latest/tutorial/security), [Node SQLite](https://nodejs.org/api/sqlite.html), [Finstore](https://finstore.by/kupit-tokeny/), [Aigenis](https://aigenis.by/), [НБРБ API](https://api.nbrb.by/exrates/rates?periodicity=0).
