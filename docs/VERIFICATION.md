# Проверка версии 0.1.0

Проверено 22 сентября 2026 на Windows x64, Node.js 24.15.0, Electron 44.4.4.

- 32 автоматических теста: средняя стоимость, комиссии, частичная продажа, отрицательные остатки, разные счета, валютный эффект, отсутствие курса, XIRR, сценарии депозита, даты купонов, технические индикаторы, валидация ввода, сохранение SQLite, редактирование и удаление связанных операций, резервная копия и восстановление, разбор источников.
- Пользовательский сценарий в настоящем Electron: пустой запуск → вклад 10 000 BYN → причина и цель покупки → полученные проценты 800 BYN → журнал, анализ, календарь, настройки → закрытие и повторный запуск с сохранёнными данными. Тестовые значения вымышлены и хранятся в отдельной `.local`-базе, в поставку не входят.
- Скриншоты пустого и заполненного обзора, анализа просмотрены. Проверено отсутствие горизонтального переполнения основного окна.
- Живые источники: 8 предложений Finstore, 3 открытые карточки Aigenis, 3 валюты НБРБ. Старая дата рыночной цены Aigenis сохранена отдельно от даты загрузки. Это проверка доступной витрины на указанную дату; состав может меняться.
- Обновление проверено также из интерфейса Electron: все три источника вернули успешный статус; инструмент из каталога сохранён в список без создания покупки. Проверена ширина окна 1060 px без горизонтального переполнения.
- Проверка зависимостей `npm audit`: 0 известных уязвимостей на момент проверки.

Не проверялись: реальный брокерский кабинет, торговые поручения, отчёты конкретного брокера, MOEX, налоги. Эти возможности не входят в текущую версию. Полный набор нестандартных облигационных графиков и договоров банков не моделируется.

NSIS-установщик собран, но установка в системные папки и удаление приложения на компьютере пользователя автоматически не выполнялись.
