# Требования, согласованные 22 сентября 2026

Windows, один пользователь, русский светлый интерфейс. Беларусь; первые площадки Finstore и Aigenis. MOEX и другие площадки позднее. Только бесплатные источники. Пользователь создаёт GitHub-репозиторий самостоятельно.

Активы: депозит, долговой токен, облигация, акция. Ручной ввод доступен без сети. Покупки, продажи, комиссии, купоны, дивиденды, проценты, пополнения, выводы. Налоги исключены из функциональности по запросу пользователя; это не утверждение о налоговых обязательствах.

Для каждой покупки сохраняются причина, цель, горизонт, ожидания, риски и условия продажи. Данные хранятся локально в SQLite, вне репозитория. Резервное копирование и восстановление. BYN — исходная валюта отображения; USD, EUR, RUB поддерживаются. База первой версии без шифрования и пароля, синхронизация между устройствами не включена.

Анализ: расчёт сценариев дохода и сравнение с депозитом, денежные потоки и доходность к погашению при наличии расписания, показатели эмитента на основе введённой отчётности, технические индикаторы по введённой истории, концентрация портфеля, пробелы в данных и чек-лист рисков. Выводы по правилам с раскрытием формул, без платного ИИ и без автоматических торговых поручений.

Публичный каталог Finstore/Aigenis обновляется по запросу, с датой и ссылкой. Каталог не означает доступ к личному кабинету, полному биржевому стакану или потоковым котировкам. Официальные курсы НБРБ, ручной ввод при недоступности сети. Автоматический импорт личных сделок и форматы отчётов брокеров — следующий этап после получения примеров.

Критерии первой версии: чистый старт без выдуманного портфеля; депозит и покупка с заметкой сохраняются после перезапуска; покупка и продажа корректно меняют остатки; комиссии включены; неизвестные цены/курсы помечены; восстановление проверяет формат базы; Windows-сборка и воспроизводимые тесты.
