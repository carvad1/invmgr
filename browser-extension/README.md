# Копирование акций и облигаций Aigenis · 0.3.0

Локальное расширение Chrome/Edge добавляет кнопку в правом нижнем углу терминала. Копирует известные рыночные поля акции или облигации без JWT, cookies и заголовков; ничего не отправляет на другой сервер.

## Установка

1. В Chrome откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `browser-extension` целиком.
4. Обновите вкладку `https://web.aigenis.by/`, чтобы перехват ответов включился до загрузки данных.

**Обновление установленного расширения:** на его карточке в списке расширений нажмите круговую стрелку. Версия должна стать **0.3.0**. Затем перезагрузите вкладку Aigenis. Папка расширения должна указывать на `browser-extension` этого проекта.

## Использование

1. Откройте нужную акцию или облигацию в Aigenis.
2. Нажмите **«Скопировать акцию»** / **«Скопировать облигацию»**.
3. В Invest Manager: **Акции → Вставить из Aigenis → Добавить акции** либо **Анализ → Облигации → Вставить из Aigenis → Показать облигации**.

При переходе на другую страницу старые данные сбрасываются. Запоздалый ответ предыдущей карточки не заменяет новую. Для списка длиннее 100 бумаг откройте отдельную карточку. Поддерживаются `bond`, `stock`, `share`, `equity`. Импорт акций проверен на реальных ответах Беларусбанк Ап17: две торговые записи карточки, 517 строк истории и статистика торгов.

Если карточка не распознана после обновления сайта Aigenis, расширение не подставляет вымышленные показатели. Сообщите номер выпуска и пример обезличенного JSON Response для обновления парсера. Не присылайте HTTP-заголовки или HAR-файл целиком: они могут содержать данные входа.

Расширение читает ответы `security_definition`, `extended_definition`, `trade_stat`, `definition_stat` и `/api/v3/definition/details/<id>/` на `invest.aigenis.by` внутри вкладки `web.aigenis.by`. Его доступ ограничен страницей веб-терминала. Копируемый JSON содержит известные поля бумаги, историю средневзвешенных цен, статистику и дополнительные сведения карточки. Для одной акции сохраняются все полученные торговые ID; дополнения связываются по definition. Наведите на кнопку, чтобы увидеть число полученных строк истории и наличие статистики. Дождитесь загрузки карточки перед копированием. Максимум 5000 строк истории за ответ; неполная страница помечается в приложении. Расширение не выполняет дополнительных запросов и не обновляется в открытой вкладке без перезагрузки. Рыночная цена по последней сделке не означает наличие текущего предложения о продаже.
